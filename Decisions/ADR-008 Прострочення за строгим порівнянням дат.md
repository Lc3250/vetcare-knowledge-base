# ADR-008 Прострочення за строгим порівнянням дат

## Контекст
Потрібно однозначно визначити, коли вакцинація вважається простроченою (ФВ-6). Задача ПР5, модуль `core/overdue.py`.

## Рішення
Вакцинація прострочена, якщо дата ревакцинації строго раніше за поточну дату (`due < today`). У день ревакцинації тварина ще не вважається простроченою. Для пари (тварина, вакцина) враховується лише остання вакцинація.

## Альтернативи
Нестроге порівняння (`<=`) зарахувало б прострочення в сам день візиту; льготний період у днях ускладнив би правило без вимоги від користувача.

## Наслідки
Граничні випадки (учора, сьогодні, завтра) покриті тестами; результат відсортовано за кількістю днів прострочення.
