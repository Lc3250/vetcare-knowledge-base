# ADR-001 Використання SQLite

## Контекст
Потрібне сховище для навчального застосунку без окремого сервера БД та без витрат.

## Рішення
Використовуємо SQLite через стандартний модуль `sqlite3`; усі запити параметризовані.

## Альтернативи
PostgreSQL (потребує сервера), JSON-файли (немає цілісності та пошуку).

## Наслідки
Просте розгортання й тести на тимчасовій базі; обмежена паралельність записів, що для навчального проєкту прийнятно. Реалізує [[Репозиторій SQLite]].
