# ADR-005 MCP-конектор на Python SDK

## Контекст
Агент має читати й наповнювати vault лише через типізовані інструменти (коміт b98411d, ПР3).

## Рішення
Конектор — Python-сервер на офіційному SDK `mcp` із трьома інструментами: ingest_note, get_note, search_notes. Працює з окремим клоном vault.

## Альтернативи
bash-скрипти (немає контракту інструмента), Node.js SDK.

## Наслідки
Стек проєкту єдиний (Python); тести запускають сервер як окремий процес.
