# Модуль нагадувань про ревакцинацію

Повертає вакцинації, ревакцинація яких настає в найближчі N днів. Чиста функція без вводу-виводу: приймає список записів і поточну дату. Для розрахунку дати використовує [[Модуль графіка ревакцинації]], а вибір останньої вакцинації для пари (тварина, вакцина) бере з [[Модуль прострочених вакцинацій]].
