# Модуль прострочених вакцинацій

Повертає список [[Тварина|тварин]] із [[Прострочена вакцинація|простроченою]] ревакцинацією на задану дату. Спирається на [[Модуль графіка ревакцинації]] і читає дані через [[Репозиторій SQLite]]. Публічна функція `latest_records` відбирає останню вакцинацію для пари (тварина, вакцина); нею користується також [[Модуль нагадувань про ревакцинацію]].
