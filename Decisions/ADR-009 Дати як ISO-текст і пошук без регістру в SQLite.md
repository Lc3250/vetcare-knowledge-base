# ADR-009 Дати як ISO-текст і пошук без регістру в SQLite

## Контекст
SQLite не має типу дати, а оператор LIKE не ігнорує регістр для кирилиці; тест виявив, що пошук «барс» не знаходив «Барсик». Задача ПР5, модуль `storage/repository.py`.

## Рішення
Дати зберігаються як текст ISO 8601 (`YYYY-MM-DD`). Для пошуку за кличкою зареєстровано SQL-функцію `py_fold` (casefold у Python), а спеціальні символи шаблону `%` і `_` екрануються.

## Альтернативи
COLLATE NOCASE (працює лише для ASCII), зберігання нижнього регістру в окремому стовпці (дублювання даних).

## Наслідки
Пошук коректно працює з кирилицею та не сприймає введені користувачем символи шаблону як підстановки; запити лишаються параметризованими.
