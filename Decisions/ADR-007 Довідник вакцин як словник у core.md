# ADR-007 Довідник вакцин як словник у core

## Контекст
Для розрахунку ревакцинації потрібен довідник вакцин (вид тварини, інтервал у днях). Задача ПР5, модуль `core/vaccination_schedule.py`.

## Рішення
Довідник зберігається як словник незмінних об'єктів `Vaccine` у шарі core. Невідома вакцина викликає `UnknownVaccineError`.

## Альтернативи
Таблиця в БД (потребує міграцій і доступу до storage з core), JSON-файл (додаткове читання файлу, немає перевірки типів).

## Наслідки
Зміна інтервалів вимагає зміни коду й тестів, зате core лишається чистим і тестується без бази. Довідник навчальний, не клінічна рекомендація.
